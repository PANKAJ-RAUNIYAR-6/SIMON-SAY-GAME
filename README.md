# 🎮 Simon Says Game

A fun and interactive memory game built using **HTML, CSS, and JavaScript**. Players must remember and repeat the sequence of flashing colors.
The game becomes more challenging as each level adds a new color to the sequence.

## 🚀 Features

- 🎯 Random color sequence generation
- 📈 Live level progression
- 🏆 High score tracking
- 📱 Mobile-friendly (Tap any box to start)
- ⌨️ Keyboard support (Press any key to start)
- ✨ Smooth button flash animations
- 🎮 Game Over screen with score display
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎮 How to Play

1. Press any key (Desktop) or tap any box (Mobile) to start.
2. Watch the flashing color sequence.
3. Repeat the same sequence by clicking the colored boxes.
4. Each level adds one new color.
5. The game ends if you click the wrong color.
